# Mendarr v1.0.3

This release improves the reliability of scans, verification, and manager-owned repairs.

## Fixed

- Normal library scans now clear old findings when the file becomes healthy and refresh their evidence.
- Background verification persists finding updates correctly after progress saves.
- Missing or unreadable files are skipped during verification instead of being marked repaired.
- Ignore decisions and existing manager links survive rescans and manager outages.
- Verification prefers the original file before guessing a local replacement and no longer picks an arbitrary neighboring video.
- Resume checkpoints are saved with completed file processing, using stable traversal order.
- Missing or inaccessible ffprobe is reported as an operational failure rather than corruption across the library.
- Delete-and-replace validates the manager's current file path and size before deleting. It retains the deletion attempt when a subsequent search fails and does not retry the destructive sequence.
- Repair jobs are claimed durably before external requests. Interrupted jobs require verification before retrying; resolved or ignored findings cancel obsolete queued jobs.
- Sonarr and Radarr queue responses retain their records correctly.
- Configured path mappings preserve directory-name case on Linux and other case-sensitive filesystems.
- The example environment file now uses the current application version.

## Validation

- 180 tests passed locally without warnings, including real ffmpeg/ffprobe media checks.
- Added Linux/Python 3.12 and Windows/Python 3.13 CI, required before container publication.

## Upgrade notes

- Back up the Mendarr data directory, update the image, and restart your existing container.
- If your environment explicitly sets `MENDARR_APP_VERSION`, update it to `1.0.3` or remove it to use the image's default.
- Jobs interrupted by a restart are marked failed with an unknown-outcome message. Verify those findings before requesting another repair.
- Delete-and-replace may now refuse stale findings or incomplete root mappings. Run verification and check your mappings before retrying.

Search acceptance still does not guarantee a replacement download. Probing checks media metadata rather than fully decoding playback. Path and size guards cannot identify every same-path, same-size replacement. Live Sonarr/Radarr and large-library performance validation remain outstanding; see `docs/reliability-review.md` for the remaining roadmap.
